Verdict

A grounded security risk-reasoning agent on Atlassian Forge. The decision is deterministic code, the AI only phrases facts it can cite.

Atlassian ForgeRovoJiraBitbucketForge LLMNVD / CISA KEV / EPSS

The problem

Security scanners produce a flood of findings and drop them into a backlog with a raw severity number attached. Someone still has to work out what actually matters here: is the affected service internet-facing, who owns it, is this CVE being exploited in the wild right now, and did we already fix the same thing in another repo last month. That triage is slow and manual, and an AI that merely summarises a finding is not trusted to make the call, because in security a confident wrong priority is worse than none.

What I built

Verdict is a grounded security risk-reasoning agent built on Atlassian Forge for Codegeist 2026. It works as two surfaces over one brain. A Forge trigger fires the moment a finding lands in Jira and runs the whole pipeline automatically, and a Rovo agent lets an analyst ask about any finding in plain language and get the same reasoning on demand.

  • The decision is deterministic code. A risk model scores each finding from severity and CVSS, multiplies by exposure and asset tier, and downgrades anything already handled, while a CISA KEV known-exploited flag forces the priority to the top. Priority and severity cannot be hallucinated, because the language model never sets them.
  • Every finding is enriched with live data: NVD fills description and CVSS gaps, EPSS adds exploit probability, and CISA KEV marks known exploitation. Each claim cites its source, and Verdict says so honestly when a source is unavailable.
  • Atlassian AI writes the explanation in plain prose, but a grounding guard checks that prose against the facts and rejects anything that names a different CVE or a mismatched score, falling back to a deterministic write-up. Nothing reaches the issue uncited.

The design decision that matters

The anti-hallucination harness is the whole point. Retrieve with code, reason with the agent constrained to the retrieved facts, verify with code so every field cites a source or is dropped, then act with code. When the core facts are missing, Verdict does not guess, it escalates: it flags that a human is needed, tags the security team, and labels the issue for review. Escalate, not invent.

Beyond a single finding

Two beats make it feel less like a scorer and more like a colleague who remembers.

  • Associative memory: it searches the project for the same CVE, links duplicates, and if the flaw was already fixed elsewhere it downgrades the new one and names where it was closed.
  • Ownership: it maps the affected service to its Bitbucket repository, reads CODEOWNERS, and assigns the issue to the real owner rather than leaving it unrouted.
